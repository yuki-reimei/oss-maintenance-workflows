# Documentation Review Checklist

Documentation is part of the maintenance surface of a project. This checklist helps keep it useful.

## Review items

- The README explains what the project is for.
- Installation or usage steps are current.
- Support and issue-reporting paths are clear.
- License information is visible.
- Security reporting guidance is available.
- Examples do not expose private data.
- Links are still valid.

## AI-assisted use

AI tools may be used to identify unclear wording, missing steps, broken structure, or inconsistent terminology. Maintainers should verify factual claims and commands before merging changes.
