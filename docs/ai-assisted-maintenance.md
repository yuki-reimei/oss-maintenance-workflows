# AI-Assisted Maintenance Notes

AI tools can reduce repetitive maintenance work, but they should support maintainer judgment rather than replace it.

## Appropriate uses

- Summarizing long issue reports
- Drafting polite maintainer responses
- Finding missing reproduction details
- Preparing release-note drafts
- Reviewing documentation for clarity
- Suggesting small code or workflow improvements

## Review requirements

Maintainers should check AI-generated output for accuracy, privacy, security, and project fit before publishing or merging it.

## Avoid

- Posting unreviewed AI-generated responses
- Sharing private user data with tools unnecessarily
- Accepting code changes without understanding them
- Inventing usage claims, metrics, or adoption numbers
