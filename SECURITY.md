# Security Policy

## Supported scope

This repository contains maintenance documentation and templates. It does not currently distribute application code or production services.

## Reporting a concern

Please open a private security advisory if the issue relates to a vulnerability in repository content or workflow guidance. If private advisories are not available, open a minimal public issue without sensitive details and request a private follow-up channel.

## Handling policy

Security-related reports are reviewed before public discussion. Fixes should avoid exposing private user information, credentials, or exploit details.
