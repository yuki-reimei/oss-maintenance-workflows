# Code of Conduct

This project expects respectful, constructive participation.

## Expected behavior

- Be clear and considerate.
- Focus feedback on the work.
- Assume public comments may be read by future contributors.
- Avoid sharing private user data or confidential project information.

## Unacceptable behavior

- Harassment or personal attacks
- Publishing private information
- Spam or repeated off-topic comments
- Abusive language or threats

Reports can be made through GitHub Issues with only the minimum public detail needed.
