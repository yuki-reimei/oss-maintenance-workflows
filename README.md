# OSS Maintenance Workflows

This repository collects practical maintenance workflows for small open-source and public-support projects. The goal is to make routine maintenance easier to review, repeat, and improve.

The project is intentionally lightweight. It focuses on the work that small maintainers often need to do consistently:

- Triage user reports and issues
- Keep support documentation accurate
- Prepare releases with a repeatable checklist
- Maintain a clear security reporting path
- Use AI coding tools responsibly for review and documentation work

## Why this matters

Small public projects often support real users even when they do not have large star counts or a large contributor base. Clear maintenance workflows help those projects stay trustworthy, responsive, and easier to contribute to.

This repository is used as a public place to document and improve those workflows.
